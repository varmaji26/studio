# **App Name**: Auth Canvas

## Core Features:

- Login: Login page for users to enter mobile number and password.
- Sign-Up: Sign-up page for new users to create an account with their mobile number and password.
- Firebase Auth: Authentication and user management handled with Firebase modular web SDK, using phone number and password authentication.
- Canvas Integration: Canvas integration for added UI customization or security features (e.g., drawing a pattern for authentication).
- Auto-Navigation: Automatic navigation to the home page upon successful login or sign-up.

## Style Guidelines:

- Primary color: Deep purple (#6750A4) to give the authentication experience a modern, secure, and sophisticated feel.
- Background color: Very light purple (#F2EFF7), almost white, maintaining a subtle association with security but in a gentle manner.
- Accent color: Teal (#49A488), an analogous color with high contrast. Suitable for interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern look; suitable for headlines or body text.
- The layout uses a minimalist style.
- Simple, outlined icons for form fields (phone, password) to maintain a clean interface.
